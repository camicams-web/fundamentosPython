📖 Sobre o Projeto

Este repositório reúne os exercícios, exemplos e atividades desenvolvidos durante o curso **Fundamentos do Python I**, oferecido pelo **SENAI**.

O objetivo foi construir uma base sólida em programação utilizando a linguagem Python, abordando desde conceitos básicos até estruturas de dados e funções.



📚 Conteúdo do Repositório

| Arquivo | Descrição |
|---------|-----------|
| 📄 `meuPrimeiroPrograma.py` | Primeiro contato com Python |
| 📓 `operadoresMat.ipynb` | Operadores matemáticos e expressões |
| 📓 `estruturasCondicionais.ipynb` | Estruturas condicionais (`if`, `elif`, `else`) |
| 📓 `lacoRepeticao.ipynb` | Estruturas de repetição (`for` e `while`) |
| 📓 `listaspython.ipynb` | Manipulação de listas |
| 📓 `dicionarioPython.ipynb` | Estrutura de dicionários |
| 📓 `manipulandoStrings.ipynb` | Manipulação de strings |
| 📓 `funcoesPython.ipynb` | Criação e utilização de funções |
| 📓 `exerciciosPython.ipynb` | Exercícios práticos para fixação |

▶️ Como Executar

Clone este repositório:

```bash
git clone https://github.com/camicams-web/fundamentosPython.git
```

Entre na pasta:

```bash
cd fundamentosPython
```

Execute um dos arquivos Python:

```bash
python meuPrimeiroPrograma.py
```

Ou abra os arquivos `.ipynb` no **Jupyter Notebook** ou **Visual Studio Code**.
